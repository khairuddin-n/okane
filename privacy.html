Kebijakan Privasi okane

Berlaku sejak 15 November 2026

okane adalah aplikasi web untuk mencatat keuangan harian. Aplikasi ini berjalan sepenuhnya di browser kamu dan tidak memiliki server. Pengembang okane tidak dapat melihat, menyimpan, atau mengumpulkan data keuanganmu.

Data yang diakses

  • okane meminta izin Google drive.file. Dengan izin ini okane hanya bisa membuat dan membuka file yang dibuat okane sendiri (spreadsheet "okane – Data"), bukan file lain di Google Drive-mu.
  • okane membaca alamat email akun Google-mu untuk ditampilkan di layar Pengaturan.

Tempat data disimpan

  • Semua catatan disimpan di spreadsheet "okane – Data" di Google Drive milikmu.
  • Salinan data disimpan di perangkatmu (IndexedDB browser) supaya aplikasi bisa dipakai tanpa internet. Salinan ini dihapus saat kamu memilih Keluar.
  • Tidak ada data yang dikirim ke server pengembang atau pihak ketiga. okane tidak memakai iklan maupun analitik.

Menghapus data dan mencabut akses

  • Cabut akses okane kapan saja di myaccount.google.com/connections.
  • Hapus data dengan menghapus file "okane – Data" dari Google Drive-mu.

Penggunaan informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use.

Kontak

Pertanyaan tentang kebijakan ini dapat diajukan lewat GitHub Issues.
